# Fixed infinite-index cores cannot cover all disjoint bridges

2026-11-19. A finite list of finitely generated infinite-index subgroups of $F(x,y)$ cannot contain, up to global conjugation, every barbell subgroup with two fixed nonempty cyclic relators and an arbitrary geodesic bridge. This is a constraint on a finite catalogue approach to the disjoint-axis part of the ordinary search.

Use the finite unbased Stallings cores of the subgroups in the proposed list. Each nontrivial such core has minimum degree two when oriented darts are counted with multiplicity. Each has a missing signed transition somewhere, since a connected core with every signed transition would be a finite cover of the ambient rose and would give finite index. A trivial subgroup may be represented by a vertex without transitions. [Stallings graph facts used in the earlier subgroup search](research-q.md).

There is one reduced word unreadable from every vertex of every core in the list. To construct it, start with the empty word and track the starting vertices from which the current prefix can still be read. Choose any surviving start. At the endpoint of its prefix, extend along a nonbacktracking path to a vertex with a missing transition, then append the missing letter. The missing letter cannot be the inverse of the last edge, because that inverse is present at the endpoint of the last edge. For an empty prefix, there is no last-edge condition.

For the nonbacktracking path, try a shortest connecting path. If it starts by reversing the last edge, first take a detour avoiding the underlying last edge: go to a cycle, traverse it and return. If deleting the last edge disconnects the core, the component at the current vertex contains a cycle because all its vertices have degree at least two except possibly that vertex. If deletion leaves the core connected and the core has rank at least two, the residual graph has a cycle because its rank decreases by one. Choose a shortest path to a cycle to avoid backtracking on the detour. In a rank-one core follow its circle in the existing direction, which reaches every vertex. This gives the asserted continuation in all cases. Each construction step kills at least one surviving start and cannot revive any other. The finite iteration therefore yields a common unreadable word.

Choose an allowed first signed edge at the first lobe and an allowed last signed edge at the second lobe, so the bridge attaches without folding at either endpoint. There are two allowed choices at each end. Insert extra letters between these edges and the unreadable word if needed to avoid cancellation. The resulting reduced bridge contains the common unreadable word as a substring. The two fixed lobes and this bridge form a folded barbell. If its subgroup were conjugate into a subgroup on the list, subgroup inclusion would induce a label-preserving immersion of the barbell into the corresponding target core. Its bridge would then be readable there, which is impossible.

The statement allows an indexing family that changes with the bridge, and it leaves finite-index overgroups outside its scope. It explains why the two-copy reductions in round two seek bridge-dependent certificates or a finite description of classes of bridges.
